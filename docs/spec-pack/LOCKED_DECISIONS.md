Avoid excessive neon, generic SaaS dashboard styling, random decorative effects, fake product UI and pixel-level cloning.

## Product media
Marketing visualizations may be original and abstract.
Whenever the actual STONIC application is shown, use real Gen 1 screenshots, recordings or approved assets.

## Admin
- Private /admin area required.
- Server-side authentication and authorization.
- No hardcoded password.
- No credentials in frontend, Git, screenshots or Spec Pack.
- Secure session handling, logout, expiration and brute-force/rate-limit protection.
- Admin pages must not be indexed.
- Only implement admin controls that actually work; no fake CMS controls.

## Deployment
- Development, preview/staging and production environments.
- HTTPS and official custom domain.
- Git-based CI/CD.
- Environment-specific secrets.
- Production smoke tests and rollback capability.
