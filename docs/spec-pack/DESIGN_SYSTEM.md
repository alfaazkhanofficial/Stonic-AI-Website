# Design System

## Visual
Near-black foundation, white primary typography, restrained gray hierarchy, approved STONIC gradients, cinematic depth, minimal borders, controlled glow and generous whitespace.

## Typography
Modern premium sans-serif with strong display hierarchy, readable body text, responsive sizing and controlled tracking. Exact font choice is an implementation decision and must be recorded before production lock.

## Motion
Scroll reveals, masked text, scale transitions, blur-to-sharp transitions, parallax, purposeful particle/line systems, horizontal storytelling where useful, hover physics and section morphing. Respect prefers-reduced-motion.

## Interaction
Buttons/navigation require hover, focus, active and disabled states and accessible labels. Motion must never be required to understand content.
