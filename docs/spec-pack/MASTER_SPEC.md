# Master Website Specification

## Purpose
Create the official public STONIC AI website for STONIC Gen 1.

## Goals
Explain STONIC, create product desire, communicate the agent system, showcase real Gen 1, drive the appropriate CTA, establish the brand and provide security/legal/support pathways.

## Non-goals
The site is not the STONIC desktop app. Do not build fake desktop functionality or make unsupported capability claims.

## Requirements
- Component-based frontend.
- Responsive desktop/tablet/mobile.
- Semantic accessible HTML.
- Keyboard navigation and visible focus.
- Reduced-motion support.
- Optimized images/video and lazy loading.
- SEO metadata, canonical URLs, sitemap and robots.
- Open Graph/social metadata.
- 404 page.
- Production error/performance monitoring as appropriate.

## Product truth
Claims must match approved STONIC Gen 1 specifications or verified implementation. Planned capabilities must be presented as planned, not shipped.

## Security
No secrets in client bundles or repository. Admin authentication and authorization are server-side. Use secure cookies/session handling, rate limiting and appropriate production security headers.
