# STONIC Gen 1 — Official Website Spec Pack

APPROVED DESIGN — READY FOR IMPLEMENTATION

This is the authoritative blueprint for the new STONIC AI website. It is a completely fresh build. It may share the caliber, cinematic pacing, premium dark aesthetic, typography approach and animation quality of high-end AI product sites, but must not clone another site's layout, copy, visuals or exact composition.

The website markets STONIC; it is not the STONIC desktop application.

Actual STONIC product UI must be shown only through real Gen 1 screenshots, recordings or approved assets. Never create a fake recreation of the application UI.

The website must include a private, authenticated admin page. Admin credentials must NEVER be stored in this pack, source code, frontend bundle, Git repository or public configuration. Credentials are created during deployment and stored only in the hosting provider's secure secrets manager.
